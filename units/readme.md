# Unidades del curso

El temario oficial (SCC-1014, TecNM) tiene **una sola fuente** en este repo:
[`docs/temario_interfaz.md`](../docs/temario_interfaz.md) (transcripción del PDF
[`docs/Lenguajes de Interfaz.pdf`](../docs/)).

## Índice de unidades

| Carpeta | Contenido |
|---|---|
| `U00-AWSAcademy/` | Alta y uso de AWS Academy (entorno principal del curso) |
| `U01-introduccion/` | Unidad 1: lecturas, lab de interrupciones GDB, ARM Virtual Hardware |
| `U01.1-setupCompilador/` | Setup del entorno ARM64 en AWS EC2 (script comentado) |
| `U01.2-Compilador-AndroidTermux/` | Setup alternativo: Android/Termux (ARM64 nativo) |
| `U01.2-Compilador-Docker-x86/` | Setup alternativo: Docker en laptop x86 + práctica con `docker ai` |
| `U01.2-Compilador-Iphone-VPN/` | Setup alternativo: iPhone + VPN |
| `U01.4-8bitComputer/` | Emulador 8 bits (Troy's Breadboard Computer) + catálogo de prácticas |
| `U02-programacion-basica/` | Unidad 2: lecturas y prácticas (cadenas, archivos) |
| `U02.01-ARM-virtual-hardware/` | Sesión: ARM Virtual Hardware |
| `U02.02-API-CoreModel/` | Sesión: API CoreModel (con `practica/`) |
| `U02.03-InLineAssembly/` | Sesión: inline assembly en C |
| `U02.03-micropython/` | Sesión: MicroPython en Pico 2W |
| `U03-modularizacion/` | Unidad 3: macros GNU as, C++ ↔ ASM, Python ctypes |
| `U04-dispositivos/` | Unidad 4: Pico 2W, OLED, UART, webserver, agentes GPIO |

Las prácticas evaluables viven en [`../practicas/`](../practicas/) y el banco de
enunciados en [`../practicas/BANCO-PROBLEMAS.md`](../practicas/BANCO-PROBLEMAS.md).
