# Políticas del Curso

- **Integridad académica:** trabajos originales; se permite inspiración con atribución. El uso de IA se rige por [AI_GUIDANCE.md](./AI_GUIDANCE.md).
- **Colaboración:** discusión permitida; código final individual salvo indicación.
- **Entregas:** fecha/hora límite en cada práctica; periodo de gracia 48h (-10%).
- **Reproducibilidad:** las entregas deben ensamblar y ejecutar con el toolchain indicado (GNU `as`/`ld`/`gcc`, `qemu` o hardware señalado); incluir instrucciones y evidencia de ejecución.
- **Comunicación:** dudas vía issues con etiqueta `question`.
