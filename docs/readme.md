🔮 La filosofía: 

- "La terminal no es antigua. Es poder sin adornos."

- "Cada comando es un hechizo. Aprende la sintaxis. Da forma a la máquina."

- "Las interfaces gráficas te muestran puertas. Las terminales te dan las llaves."

- "El usuario de una terminal no navega entre límites haciendo clics; los supera mediante scripts."
