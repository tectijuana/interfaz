# Anexo: Uso de Inteligencia Artificial

## 1. Introducción

Para la realización de la investigación sobre **pruebas unitarias de código en ensamblador utilizando Unity y Ceedling**, se utilizó Inteligencia Artificial como herramienta de apoyo para comprender el tema, localizar fuentes bibliográficas y organizar la información que debía ser consultada.

La herramienta utilizada fue **ChatGPT**, principalmente como apoyo durante la etapa de investigación.

---

## 2. Prompts utilizados

### Prompt 1

> “En mi clase de lenguaje de interfaz me pidieron una investigación sobre pruebas unitarias de código en ensamblador con Unity / Ceedling, quiero que me expliques algo de eso.”

**Resultado obtenido:**

El LLM proporcionó una explicación general sobre las pruebas unitarias y su utilidad para verificar el funcionamiento de partes individuales de un programa.

También explicó la relación entre **Unity**, como framework para realizar pruebas unitarias en lenguaje C, y **Ceedling**, como una herramienta que facilita la organización, compilación y ejecución automatizada de pruebas.

A partir de esta explicación se pudo comprender que, aunque Unity está orientado principalmente a código en C, puede utilizarse como parte de un entorno de pruebas para funciones relacionadas con código ensamblador cuando estas pueden ser integradas y llamadas desde C.

La información obtenida sirvió como introducción al tema y permitió identificar los conceptos principales que debían investigarse posteriormente.

---

### Prompt 2

> “Quiero que me proporciones fuentes bibliográficas para investigar sobre el tema.”

**Resultado obtenido:**

El LLM proporcionó diferentes fuentes bibliográficas y documentación relacionada con las pruebas unitarias en C, Unity y Ceedling.

Entre las fuentes recomendadas se incluyeron principalmente:

- **Unity**, documentación oficial del framework de pruebas unitarias.
- **Unity Getting Started**, para conocer el proceso básico de creación y ejecución de pruebas.
- **Ceedling**, documentación oficial de la herramienta para automatización y administración de proyectos de pruebas en C.

Estas fuentes permitieron localizar información directamente relacionada con las herramientas utilizadas en el desarrollo de pruebas unitarias y sirvieron como base para realizar la investigación.

---

### Prompt 3

> “Tomar esas 4 fuentes y decirme exactamente qué páginas/secciones leer de cada una y qué información sacar de cada sección.”

**Resultado obtenido:**

El LLM organizó las fuentes bibliográficas previamente seleccionadas e indicó qué páginas o secciones de cada fuente debían consultarse para realizar la investigación.

También se especificó qué información podía obtenerse de cada sección, por ejemplo:

- Conceptos fundamentales de las pruebas unitarias.
- Funcionamiento del framework Unity.
- Forma de crear y ejecutar pruebas unitarias.
- Organización de proyectos mediante Ceedling.
- Automatización de la compilación y ejecución de pruebas.
- Relación entre las pruebas unitarias y el código que se desea verificar.

Esta organización permitió delimitar la investigación y evitar consultar información que no fuera directamente relevante para el tema.

---

## 3. Uso de la información obtenida

La información proporcionada por la Inteligencia Artificial se utilizó como **apoyo para orientar la investigación**, identificar conceptos importantes y localizar documentación relevante.

Las fuentes originales fueron consultadas para obtener y verificar la información utilizada en el trabajo. La IA se utilizó principalmente como herramienta de orientación y apoyo durante el proceso de investigación, no como sustituto de las fuentes bibliográficas.

---

## 4. Herramienta de Inteligencia Artificial utilizada

**Herramienta:** ChatGPT

**Uso principal:**

- Comprender conceptos relacionados con las pruebas unitarias.
- Identificar la relación entre Unity y Ceedling.
- Localizar fuentes bibliográficas.
- Organizar las fuentes y determinar qué información consultar.
- Resolver dudas relacionadas con el tema de investigación.

---

## 5. Reflexión crítica

El uso de la Inteligencia Artificial durante esta investigación fue útil principalmente como una herramienta de orientación. Al inicio, el tema de las pruebas unitarias de código en ensamblador utilizando Unity y Ceedling podía resultar confuso debido a que involucra diferentes herramientas y lenguajes. Los primeros prompts permitieron comprender mejor la relación entre las pruebas unitarias, Unity y Ceedling.

Sin embargo, la información proporcionada por la IA no se tomó directamente como una fuente bibliográfica. Fue necesario consultar las fuentes originales para comprobar la información y determinar cuáles datos eran relevantes para la investigación. Esto es importante porque una respuesta generada por IA puede contener información incompleta, simplificada o que necesite ser verificada.

Uno de los principales beneficios de utilizar IA fue la posibilidad de organizar el proceso de investigación. Los prompts ayudaron a identificar los conceptos principales que debían investigarse y las secciones de las fuentes que podían ser más útiles.

Finalmente, considero que la IA debe utilizarse como una herramienta de apoyo y no como un sustituto de la investigación. En este trabajo fue útil para comprender el tema, resolver dudas y orientar la búsqueda de información, pero la consulta de las fuentes originales y el análisis de la información fueron necesarios para realizar la investigación final.
