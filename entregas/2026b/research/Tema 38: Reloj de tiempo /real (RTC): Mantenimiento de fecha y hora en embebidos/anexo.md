# Anexo — Bitácora de uso de LLM

**Tema:** Reloj de tiempo real (RTC): Mantenimiento de fecha y hora en embebidos
**Autor:** Vazquez Sanchez Cesar Ricardo

---

## Herramienta utilizada

* **Nombre:** ChatGPT

---

## Prompts utilizados

### Prompt 1

> "Necesito una explicación detallada del tema: Reloj de tiempo real (RTC): mantenimiento de fecha y hora en sistemas embebidos. Es un tema de investigación de la materia de Lenguajes de Interfaz, ayúdame a entender este tema, descripción de lo que es, de qué se trata y ejemplos fáciles de comprender."

**Resultado obtenido:**

El LLM proporcionó una explicación general pero de fácil comprensión sobre los relojes de tiempo real (RTC), describiéndolos como circuitos utilizados para mantener una referencia de fecha y hora dentro de un sistema. También explicó diferencias como la de un RTC y un temporizador común.

Esta primera explicación fue utilizada principalmente para comprender el tema y partir de esta base antes de comenzar a estructurar la investigación.

---

### Prompt 2

> "Dame fuentes confiables de las cuales obtener la mejor información para mi investigación, y yo seleccionaré las que usaré."

**Resultado obtenido:**

El LLM dio diferentes fuentes relacionadas con el funcionamiento de los RTC y documentación técnica de fabricantes. A partir de las fuentes se seleccionaron cinco para utilizar como base de la investigación:

* **Analog Devices — DS3231**
* **NXP — PCF8563**
* **Microchip — Getting Started with RTC (TB3213)**
* **Microchip — AVR134: Real Time Clock (RTC) Using the Asynchronous Timer**
* **Microchip — Real-Time Clock and Calendar Technical Brief (TB3124)**

---

### Prompt 3

> "En base a esta estructura, introducción y fuentes que seleccioné de mi investigación, realiza el desarrollo técnico de mi README lo más completo posible."

**Resultado obtenido:**

El LLM generó una propuesta para el desarrollo técnico siguiendo la estructura planteada para la investigación. El contenido se organizó en los siguientes temas:

1. **¿Qué es un RTC y para qué sirve?**
2. **¿Cómo mantiene la hora?**
3. **RTC interno y RTC externo.**
4. **Precisión y alimentación de respaldo.**
5. **Aplicaciones en sistemas embebidos.**
6. **Comparación y análisis.**

La propuesta ayudó a organizar los conceptos obtenidos de las cinco fuentes seleccionadas. El desarrollo generado no fue utilizado completamente de forma directa; este se revisó y modificó, se eliminaron partes innecesarias para la investigación y se conservaron únicamente las ideas y conceptos que se consideraron adecuados para el documento.

---

## Reflexión crítica

El uso del LLM fue útil durante las primeras etapas de la investigación. La primera explicación permitió comprender de manera sencilla qué es un RTC, cuál es su función y por qué es diferente de un temporizador utilizado solamente para medir intervalos.

Otra utilidad importante fue la búsqueda inicial de fuentes. En lugar de utilizar directamente toda la información proporcionada por el LLM, se seleccionaron cinco fuentes técnicas de fabricantes y se utilizaron estas como base para desarrollar la investigación.

Durante la elaboración del README también fue útil solicitar una estructura para organizar el desarrollo técnico. Sin embargo, la respuesta generada por el LLM tuvo que ser revisada y modificada para adaptarla al estilo del trabajo, ya que algunas explicaciones eran más extensas de lo necesario o utilizaban una redacción que no correspondía completamente con la forma en que se quería presentar la investigación.

También se tuvo en cuenta que una respuesta generada por un LLM no debe considerarse automáticamente como una fuente técnica. Por este motivo, el desarrollo final se basó únicamente en las cinco fuentes seleccionadas y no simplemente en la información proporcionada por la inteligencia artificial.
